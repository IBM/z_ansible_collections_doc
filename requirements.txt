# Python packages needed to build the site HTML with `make html` and to run the
# `site-*.yml` playbooks. Requires Python 3.13 or later (Sphinx 9.x), verified
# on 3.13 and 3.14.
#
# The documentation (RST) for each collection is generated in that collection's
# own repository and committed there; this repository only renders it, so
# `ansible-doc-extractor`, linters and `galaxy-importer` are not needed here.
# See the `docs/Makefile` of each collection for those. `ansible-core` (not the
# full `ansible` package) is enough to run the playbooks, which only use
# builtin modules.
#
# The packages under "Direct" are the ones this repo uses; everything under
# "Transitive" is pinned only so builds are reproducible. To refresh, in a clean
# venv run `pip install Sphinx sphinx-rtd-theme sphinx-copybutton sphinx_design
# ansible-core`, then `pip freeze`, and check the result with `pip-audit`.
#
# `make version-html` requires `sphinx-versions`, which imports `pkg_resources`
# (removed in setuptools 81, absent from Python 3.12+ venvs); it is not used by
# the site build, to use it: `pip install sphinx-versions "setuptools<81"`.
################################################################################
